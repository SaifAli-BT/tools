SAIF ALI PORTFOLIO WEBSITE

Files:
- index.html: website structure and content
- style.css: colors, layout, and visual design
- script.js: animations, navigation, project filters, chart, and contact form behavior

HOW TO UPLOAD TO GITHUB:
1. Open your GitHub repository named "tools".
2. Click "Add file" > "Upload files".
3. Select index.html, style.css, and script.js from this folder (you can select all three).
4. Scroll down to "Commit changes", keep the default message, and click "Commit changes".

HOW TO PUBLISH:
1. In the repository, click Settings.
2. In the left menu, click Pages.
3. Under "Build and deployment", select "Deploy from a branch".
4. Select branch "main" and folder "/ (root)", then click Save.
5. Wait a few minutes. GitHub Pages will show the website address on the Pages settings screen.

IMPORTANT:
- The CSS and JavaScript are separated into their own files, but the website content and design are preserved.
- The portrait image "saif-ali.jpg" is referenced by the HTML but was not included in the upload. The page has an "SA" fallback if the image is missing. To show a portrait, add your image to this same folder and name it exactly saif-ali.jpg.
- The social preview also refers to "saif-ali-logo.jpg"; that image was not included. This is optional and does not prevent the website from loading.
- The page uses external libraries and fonts from online CDNs, so some animations/icons require an internet connection.
- Check that all personal details and experience claims in the portfolio are accurate before publishing.
